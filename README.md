### 바르굴 — “공간을 읽을 수 있는가?”

실제 게임 코드의 자동 바렐 측정을 반영한 공략입니다. 돌진·빙검·십자는4단계, 구슬은 이후 독립 AI 변경을 반영했습니다.

- 빙창3연격: 첫 `!`부터 줄을 바꾸고3타 뒤에 돌아오면 반격할 수 있습니다. 공격 직전의 옅은 냉기 표시와 각 타의 밝은 창 궤적·바닥 범위로 공격 구간을 읽으세요. 2페이즈3타는 앞쪽13–14장에서만 공격합니다.
- 쾌속돌진: 흰 깜빡임을 보면 줄을 바꾸고, 2페이즈에는 돌아올 때 한 번 더 줄을 바꾸세요. 거리100/150/220/270 시험에서12틱 지연 반응도 모두 무피격이었지만, 먼 거리에서는 여유가0~1틱뿐입니다. 왕복 뒤R34에는 시험 동선에서27틱째 반격했습니다.
- 빙검소환: 계속 걸어 다 피한 뒤, 마지막 빙검이 다 떨어진 후의R24에 반격을 노리세요. 화면 끝까지 멀어지면 돌아오는 데48~49틱이 걸려 반격 시간을 놓칩니다. 시동·집중은 공격으로 끊을 수 있으며 이미 놓인 표식은 남습니다.
- 십자빙결: 가로 팔이 화면 전체를 덮으므로 대각선으로만 빠지세요. x만 또는 깊이만 움직이면 맞습니다. 2페이즈에는 두 번째 표식에서도 다시 대각선으로 이동하세요.

- 창휘두르기: 1페이즈는 이른 점프로 피할 수 있었고2페이즈는 점프 시험에서 모두 맞았습니다. 줄을 바꾼 뒤 돌아오면R22 안에 첫 타가 들어갑니다.

## 조작과 편의 기능

- 이동: WASD / 방향키, 점프: Space / Ctrl, 공격: J / Z
- 대시: Shift 또는 같은 좌우 방향키를 두 번
- 필살기: K / X, 뇌격: I / V
- 기술: U 돌진 찌르기, H 내려찍기, O 회전 베기, P 점프 강하
- 일시정지: ESC / 화면의 정지 버튼, 소리: M

타이틀과 일시정지의 **설정**에서 키, 음악·효과음 음량, 화면 흔들림·섬광, 터치 조작을 변경합니다. 터치 조작은 이동과 공격의 동시 입력을 지원합니다. 작은 화면에서는 가로 방향을 권장합니다.

**직접 연습**에서는 이동·명중·점프·대시·기술을 피해 없이 연습할 수 있습니다. 연습은 진행 저장과 기록을 변경하지 않습니다.

진행은 **스테이지 시작 지점**에 자동 저장됩니다. 클리어하면 다음 스테이지가 저장되고 마지막 스테이지 클리어 시 이어하기 저장은 해제됩니다. 다시 시작·이어하기는 시작 시점의 체력, 목숨, 점수와 자원을 복원합니다. 현재 웨이브 도중의 위치는 저장하지 않습니다.

설정·진행·최고 점수·스테이지별 최고 랭크는 현재 브라우저의 localStorage에 저장됩니다. 브라우저/주소가 달라지면 별도 기록이며, 저장이 제한된 환경에서도 플레이할 수 있지만 기록은 남지 않습니다.

랭크는 누적 피해, 사망 횟수, 시간, 최대 연속 히트로 계산합니다. 회복이나 부활로 피해 기록은 지워지지 않으며 S/A는 사망 없이 클리어해야 받을 수 있습니다.

## 회귀 검증

v1.10의 보스 4~5와 군단 병사 4종은 첨부 디자인 시트를 프레임 단위로 잘라 만든 스프라이트 아틀라스(`legion_sprites.js`)로 그립니다. 황금왕 아우렐리온은 `hd_sprites.js`의 프레임 아틀라스를 씁니다. `score.js`에는 일반 스테이지 5곡과 보스 전용 5곡의 악보 및 Web Audio 합성 악기가 있습니다. 보스 등장 시 전용 음악으로 전환하며, 외부 음원 다운로드는 필요하지 않습니다.

Node.js와 Chrome/Chromium/Edge가 있는 환경에서:

```powershell
node tests/regression.cjs
```

검증 환경: Windows, Node.js 24.21.0, Chrome 155. 다른 설치 경로는 `BROWSER_PATH` 환경 변수로 지정합니다. 테스트는 임시 로컬 서버와 격리된 브라우저 프로필을 사용합니다.

튜토리얼의 네 가지 화면 크기, 돌진 판정, 입력 보관·만료, 일시정지, 랭크, 연습, 저장·복원, 키 변경, 다중 터치, 위험 지대, 보스 패턴, 5개 스테이지 전환과 단일 HTML 번들을 검사합니다. 화면 캡처는 실행 결과에 표시되는 임시 폴더에 남깁니다. 스테이지 전환 검사는 적을 강제로 처치하므로 실제 난이도 플레이테스트를 대신하지 않습니다.
