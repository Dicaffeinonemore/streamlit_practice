# 흑월의 기사 — BLACK MOON KNIGHT

## 모바일 화면 실험실

사용자가 제공한 mini 가로 설정은 `data/mobile-layout-iphone-mini.json`에 보관하고 `mobile-display.js`에서 적용합니다. iPhone의 375×812 논리 화면 계열이 가로로 회전하면 좌우 50px·하단 21px을 최소 안전 여백으로 사용합니다. 실제 기기 안전 여백이 더 크면 그 값을 우선합니다. 게임의 960×540 전투 좌표와 16:9 비율은 유지하고 표시 크기만 남은 영역에 맞춥니다. 사용자가 저장한 조작키 배치는 우선 보존합니다. 브라우저에서는 mini 모델명을 직접 구분할 수 없어 동일 논리 화면 크기의 iPhone에도 이 규칙이 적용됩니다.

게임 타이틀의 **모바일 화면 실험실 ↗** 링크 또는 로컬 서버의 `/mobile-lab.html`에서 엽니다.
전용 실행: `python tools/mobile_lab_server.py` (출력된 주소를 브라우저에서 열기).

- 아이폰·갤럭시 대표 프리셋 10종(iPhone 12 mini·13 mini 포함), 가로/세로, 직접 입력, 브라우저 도구 모음 높이와 안전 여백을 비교합니다.
- 실제 게임을 실행하며 조작키 잘림·겹침·44px 미만 영역을 검사합니다. 전체 기종 검사는 현재 캐릭터와 키 배치로 20개 화면 조건을 비교합니다.
- 키 드래그 편집 또는 개별 위치·크기·숨김 설정 후 기종/방향별로 저장하고 JSON을 내보내거나 불러올 수 있습니다.
- **이 브라우저의 게임에 조작키 적용**은 같은 주소의 게임 설정에 키 배치만 저장합니다. 게임을 새로고침하면 반영됩니다. 기종별 자동 전환이나 다른 사용자에게 배포되는 기본값 변경은 아닙니다.
- 테스트 저장 기록은 `bmk_lab_` 공간으로 분리합니다. 가상 화면 크기·안전 여백은 검사 조건이며 일반 게임에 적용되지 않습니다.
- 프리셋은 대표값입니다. 실제 브라우저 확대 설정과 주소창 상태에 맞춰 값을 수정하세요. Safari/삼성 인터넷의 렌더링, 멀티터치, 성능은 실기기에서 별도로 확인해야 합니다.

검증: `MOBILE_LAB_SUITE=1 node tests/regression.cjs` (PowerShell: `$env:MOBILE_LAB_SUITE='1'; node tests/regression.cjs`).

> 원본 아트(약 560MiB)는 저장소에서 제외하고 각자 백업합니다. 게임 실행과 회귀 테스트에는 필요 없습니다. [원본 아트 관리](docs/source-assets.md)

새 게임의 캐릭터 선택에서 바렐(흑기사) 또는 비에사(궁수)를 고릅니다. 선택한 캐릭터는 저장·이어하기·재시작에 함께 기록됩니다. 이전 저장은 바렐로 유지됩니다.

비에사는 J 화살/공중 하강 사격, H 근접3연타, U 6발 연사, L 유지·해제 저격, O 돌진→지상 백플립, P 돌진→공중 백플립, K 필살기 ‘흑월 난사’(SP100)를 사용합니다. U/L/O/P는 기존 같은 키의 기술 쿨타임을 사용합니다. 화살은 무제한입니다. 이동·점프·대시·메뉴는 공통이며 바렐은 기존 조작을 유지합니다. 보스 챌린지에서도 보스를 고른 뒤 캐릭터를 선택할 수 있습니다.

개정 ZIP의 Viesa_Revised 모션8장·기본 이펙트·필살기 이펙트를 사용하며 마스터는 사용하지 않습니다. 원본·프레임 수·시트별 크기 보정·조작 및 변경 파일은 [v1.41 패치 노트](patch_note/patch_1.41.txt)에 있습니다. 빌드: `python tools/viesa_build.py`. 바렐과 동일한 무손실 PNG 아틀라스/피벗 형식을 사용합니다. 이전 기록은 [v1.40](patch_note/patch_1.40.txt), [v1.39](patch_note/patch_1.39.txt)에 있습니다.

### 흑월의 갑주왕 — “지금까지 배운 것을 다 쓸 수 있는가?”

몸과 두 개의 거대한 건틀릿 주먹이 따로 움직입니다. 줄 바꾸기·참기·바닥 읽기·점프를 모두 씁니다. 설계는 [boss5_sovereign.md](docs/boss5_sovereign.md)에 있습니다.

- 주먹은 방패입니다. 공격이 주먹에 먼저 닿으면 몸에는 들어가지 않습니다. 주먹이 공격하러 나갔을 때, 공격 뒤 멈춰 있을 때, 부서져 누워 있을 때 치거나 등 뒤로 돌아가세요. 뒷주먹은 높이 떠 있어 등은 비어 있습니다.
- 주먹마다 체력이 따로 있습니다(1페이즈 140, 2페이즈 180). 찌르기·내려찍기·강하·필살기 같은 넉다운 공격은 주먹에 1.5배입니다. 주먹을 부수면 그로기가 크게 쌓이고, 두 주먹이 함께 누우면 즉시 그로기입니다.
- 손목 핵 빛을 읽으세요. 흰빛은 아머 공격, 빨간빛은 붙잡기입니다. 바닥 표식은 떨어질 자리, 투구 틈이 밝아지면 광선입니다.
- 직격: 흰빛 뒤 고정된 줄로 날아옵니다. 줄을 바꾸고, 같은 줄로 돌아올 때 한 번 더 피하세요.
- 추적 내려찍기: 그림자가 따라오다 멈추고 빠르게 깜빡이면 그때 빠져나오세요. 박힌 50틱 동안 주먹을 칠 수 있습니다.
- 망치질: 세 번 내려찍습니다. 표식이 생길 때마다 옆으로 비키세요. 세 번째만 넉다운입니다.
- 붙잡기: 빨간빛이면 줄을 바꾸세요. 잡히면 공격·방향키를 4번 연타해 탈출합니다. 탈출하면 주먹이 경직되고 피해를 입습니다.
- 협공: 두 주먹이 양옆에 섭니다. 점프로는 못 피하니 줄을 바꾸세요.
- 지면 파동: 두 주먹이 높이 올라갔다 땅을 치면 낮은 파동이 무대 전체로 퍼집니다. 점프하세요.
- 철벽: 앞에서 치는 공격은 모두 막힙니다. 등 뒤로 돌거나, 주먹이 내려앉는 40틱을 기다리세요.
- 회오리: 두 주먹이 몸 둘레를 두 바퀴 돕니다. 반경 밖으로 나가 있다가 끝나고 흔들릴 때 치세요.
- 손등 치기: 빈틈이 아닐 때 몰아치면(1페이즈 3대, 2페이즈 2대) 가까운 주먹이 옆으로 쳐냅니다. 몰아치지 말고 빈틈을 노리세요.
- 투구 광선: 투구 틈이 밝아지고 바닥에 줄이 표시되면 줄을 바꾸세요.
- 유성 낙하(2페이즈): 표식 네 개가 번갈아 떨어집니다. 계속 움직이세요.
- 흑월 강림(2페이즈 궁극기): 합쳐진 거대 주먹이 화면 끝에서 끝까지 낮게 두 번 쓸고 갑니다. 두 번 점프한 뒤, 무릎 꿇은 120틱 동안 크게 반격하세요.

소버린 그림 재생성: `python tools/build_sovereign_art.py`.

## 조작과 편의 기능

- 이동: WASD / 방향키, 점프: Space / Ctrl, 공격: J / Z
- 대시: Shift 또는 같은 좌우 방향키를 두 번
- 필살기: K / X, 뇌격: I / V
- 기술: U 돌진 찌르기, H 내려찍기, O 회전 베기, P 점프 강하
- 일시정지: ESC / 화면의 정지 버튼, 소리: M

타이틀과 일시정지의 **설정**에서 키, 음악·효과음 음량, 화면 흔들림·섬광, 터치 조작을 변경합니다. 터치 조작은 이동과 공격의 동시 입력을 지원합니다. 작은 화면에서는 가로 방향을 권장합니다.

**직접 연습**에서는 이동·명중·점프·대시·기술을 피해 없이 연습할 수 있습니다. 연습은 진행 저장과 기록을 변경하지 않습니다.

진행은 **스테이지 시작 지점**에 자동 저장됩니다. 클리어하면 다음 스테이지가 저장되고 마지막 스테이지 클리어 시 이어하기 저장은 해제됩니다. 다시 시작·이어하기는 시작 시점의 체력, 목숨, 점수와 자원을 복원합니다. 현재 웨이브 도중의 위치는 저장하지 않습니다.

설정·진행·최고 점수·스테이지별 최고 랭크는 현재 브라우저의 localStorage에 저장됩니다. 브라우저/주소가 달라지면 별도 기록이며, 저장이 제한된 환경에서도 플레이할 수 있지만 기록은 남지 않습니다.

랭크는 누적 피해, 사망 횟수, 시간, 최대 연속 히트로 계산합니다. 회복이나 부활로 피해 기록은 지워지지 않으며 S/A는 사망 없이 클리어해야 받을 수 있습니다.
