# 황금왕 아우렐리온 (AURELION THE GOLDEN KING) — 프레임 데이터 설계

> 빛이 곧 정의요, 내가 곧 왕이다.

**플레이어에게 던지는 질문:** 참을 수 있는가? 빠르고 섞이는 검술 사이에서 진짜 빈틈만 노리고, 수호의 자세 앞에서는 손을 멈출 수 있는가?

단위: 60fps 프레임(f), 240px 세트의 픽셀(대기 자세에서 왕관 끝~발 240px, 든 칼은 빼고 잼). 표는 JSON에서 자동 생성.

## 수호의 자세 규칙

- **언제:** 플레이어가 170px 안에서 공격을 시작했고 수호 자세 쿨타임이 끝났을 때 (공격 대신 이번 판단을 자세로)
- **몰아칠 때:** 빈틈이 아닐 때 3대(2페이즈 2대) 맞으면 다음 행동은 수호의 자세
- **받아치기:** 자세 중 넉다운 속성이 없는 공격 → 무효, 받아치기(3번) → 반격 찌르기(4·5번)
- **자세 붕괴:** 자세 중 넉다운 속성 공격 → 피해는 들어가고 자세 붕괴(7~9번), 그로기 +25
- **참으면:** 60f 동안 안 맞으면 9번 24f 틈
- 반응 확률: 1페이즈 35%, 2페이즈 45%

## 이것만 기억

- 금빛 깜빡임(수호의 자세)에는 손을 멈춘다. 참으면 60f 뒤 24f 틈, 무거운 기술(3타·찌르기·내려찍기)이면 자세가 깨진다
- 3연참은 1·2타에서 멈추기도 한다. 웅크림(올려치기 예고)을 보고 피한 뒤 26f에 반격
- 황금중파참은 46f 예고 + 충격파. 줄을 바꾸거나 점프로 넘고, 칼이 박힌 66f 동안 몰아친다
- 엄벌 표식은 따라오지 않는다. 표식 밖으로 한 발 → 검을 짚은 54f가 반격 시간
