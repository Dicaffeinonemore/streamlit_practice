# 바렐 combo0 10프레임 제작 검토 — 그림 제작 미완료

2026-10-25. **10프레임 애니메이션은 완성하지 않았다.** 신규 A를 두 차례 제작했으나 기존 캐릭터의 디자인과 픽셀 밀도를 유지하지 못해 모두 불채택했다. 승인된 신규 프레임은 0장이다. 사용자가 지정한 품질 조건에 따라 미완성 그림을 임의로 사용하거나, 기존 그림의 복제·위치 이동·반복으로 프레임 수를 채우지 않았다.

기존 600ms/350ms 6프레임 Aseprite 원본, 백업, PNG/JSON, 테스트 페이지, 어댑터, CLI 및 전투 코드는 수정하지 않았다. 신규 10프레임 Aseprite/스프라이트 시트/재생 페이지는 아직 생성하지 않았다.

## 그림 승인 시 검사할 기준

성인 체형과 머리/몸통 비율, 검은 갑옷 판의 구조, 붉은 투구 장식, 붉은 망토, 대검 길이·두께·가드·손잡이를 원본과 대조한다. F1/F2/F3를 인접 프레임으로 겹쳐 손목과 손잡이가 분리되지 않는지 확인한다. 검 끝의 경로뿐 아니라 골반, 어깨, 팔꿈치, 손목도 함께 추적한다. 망토만 몸통보다 약간 늦게 반응하게 한다.

발 바닥 높이가 같은 것과 지지발이 고정된 것은 다른 조건이다. 기존 발 영역 중심값만으로 같은 발을 추적할 수 없으므로 오프셋을 미리 만들어 넣지 않는다. 승인된 그림에서 같은 지지발과 골반을 표시한 뒤, 기존 90~200ms/8 월드 단위 전진과 대조하여 필요한 렌더링 오프셋만 산출해야 한다. 실제 이동량과 충돌 판정에는 반영하지 않는다.

원본 기준점 [67,143]은 등록 기준으로만 사용하고, 칼끝에 여백이 필요하면 공통 캔버스를 확장하며 기준점도 같은 양만큼 옮긴다. 프레임마다 캐릭터를 따로 확대·축소하여 맞추지 않는다.

## 전투 및 검증 상태

계획은 기존 공격 350ms, 판정 [128.5,230)ms, 콤보 연결 267.5ms를 그대로 사용한다. 가속 B의 마지막 1.5ms부터 C/F3/F4 수정 자세까지 판정이 걸리고 회수 D는 230ms에 시작한다. player.t × MS 기반 어댑터, 기존 hitSet/히트스톱/취소/입력 버퍼는 변경하지 않았다.

검증 상태를 구분한다.

- 계획한 10개 duration의 합계와 구간: 검사 가능, 합계 350ms.
- 현재 6프레임의 원본/백업/지속 시간/외부 시계 샘플링: 기존 테스트로 재검증.
- 10프레임의 실제 재생·검 궤적·장비 일관성·접지·판정과 그림 일치: **검증 불가 — 승인된 그림이 아직 없음.**
- 6프레임과 완성 10프레임의 나란한 재생 비교: **미제작.** 불채택 후보나 반복 프레임을 비교용 완성본으로 표시하지 않았다.

다음 제작 단계는 원본 픽셀 캔버스에서 A/B/C/F4 수정/D를 직접 그려 디자인과 관절·접지 검수를 통과시키는 것이다. 그 후 별도 10프레임 `.aseprite`, 메타데이터와 비교 페이지를 구성하고 기존 `tools/export-sprites.ps1`로 내보낼 수 있다.
