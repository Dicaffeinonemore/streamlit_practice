흑월의 기사 v1.38 — 5스테이지 보스 교체: 흑월의 갑주왕
기록일: 2026-10-21
설계: docs/boss5_sovereign.md

추가 수정 — 화면 확인 후 연출 보정
- 바닥 표식(추적 내려찍기·망치질·유성 낙하): 5스테이지의 어두운 바닥에서 잘 보이지 않던 표식을 키웠다.
  어두운 구덩이 + 자홍 테두리 + 표식 그림 1.25배. 떨어지기 직전에는 흰 테두리로 빠르게 깜빡인다.
- 흑월 강림: 거대 주먹 뒤의 가로 꼬리 이펙트가 투구 광선처럼 보여, 바닥을 긁는 낮은 파동과 돌 파편으로 교체.
- 잔해: 주먹이 몸에 겹친 채(궁극기 도중 등) 죽으면 쓰러진 주먹이 몸 잔해 밑에 가려졌다.
  몸에 겹친 주먹은 몸 양옆으로 떨어지게 하고, 승리 연출의 어두운 화면에서도 보이도록 잔해 아래에 자홍 잔불(타원)을 깐다.
- 전투 판정·수치 변화 없음. 수정 후 보스전 전체(등장~사망)를 다시 실행해 런타임 오류 0건 확인.

1. 보스
- 5스테이지 마지막 웨이브의 boss5를 흑월의 갑주왕으로 교체. 1페이즈 HP2400 → 변신(무적 약250틱) → 2페이즈 HP3000.
- 보스 = 몸 + 앞주먹 + 뒷주먹. 주먹은 각자 위치·상태·체력·판정을 가진 독립 물체다.
- 주먹은 방패: 바렐의 공격은 주먹을 먼저 검사하고, 주먹에 맞은 공격은 몸에 들어가지 않는다.
- 주먹 체력 140 / 180(2페이즈), 넉다운 기술 1.5배. 부서지면 그로기+40, "주먹 파괴!", 1페이즈480 / 2페이즈360틱 뒤 재생.
- 두 주먹이 동시에 누우면 즉시 그로기.
- 패턴: 직격, 추적 내려찍기, 망치질, 붙잡기(연타 탈출 8회/50틱), 협공, 지면 파동, 철벽, 회오리, 손등 치기,
  유성 낙하(2P), 흑월 강림(2P 궁극기), 투구 광선.
- 위험 판정 사이 20틱 규칙은 스케줄러가 시작을 미루는 방식으로 지킨다. 동시 패턴 1P 1개 / 2P 2개.
- 갑주왕의 체력 문턱 증원은 끔. 처음 웨이브의 적은 유지.
- 보스 체력바 위 기술 이름은 마지막으로 시작한 패턴 이름을 표시.

2. 그림
- tools/build_sovereign_art.py: 바르굴 분리 도구(build_vargul_art.split_actor 등)를 재사용. 07_Retro_8bit은 읽지 않음.
- 몸 16동작(1P 7 + 변신 + 2P 8), 주먹(1P·2P 12장, 1P 핵 꺼진 그림 3장, 2P 쓰러짐 4장, 거대 주먹 6장), 이펙트 9줄.
- 2페이즈 투구 달·균열 반짝임: 자홍 마스크를 90틱 주기로 더하기 혼합(바르굴 문신 방식).
- 저장: 월드px당 1.5 아틀라스px, WebP q86 / 이펙트 q80. sovereign-art.js 약6.1MB.

3. 연결
- 새 파일: sovereign-art.js, sovereign-data.js, sovereign-runtime.js (index.html·server.py 로드 순서: 바르굴 다음, item 앞).
- game.js·release.js: 바르굴과 같은 위치에 isSovereign 분기 추가. 옛 블랙 문 엠페러 코드·그림은 그대로.
- 끄기: 스크립트 로드 전에 globalThis.SOVEREIGN_OVERRIDE=false → 블랙 문 엠페러.

4. 설계와 다르게 구현한 점
- 주먹 크기: 마스터의 주먹 길이(손목~주먹 끝) ÷ 몸 높이(왕관 제외) = 0.425 → 58.7 월드px를 옆모습 1번의 길이에 적용.
  2P 주먹은 가시 때문에 +15%, 거대 주먹은 주먹 길이의 2.2배(설계에 값 없음).
- 왕관 가시는 idle 1장에서 잰 비율(키의 6%)로 일괄 제외. 1P 각 시트는 자기 1장의 서 있는 키로 맞춤.
- 2P 크기는 사바톤 길이만 맞춤(정강이는 자동 측정 불가). command_p2는 망토가 발을 가려 14% 벗어나 2P 중앙값 사용.
- awaken 시트는 첫 장(무릎)을 kneel 9장 높이에 맞춤.
- 주먹 몸 상자는 고정 크기(x±26, 높이±22, 깊이±16). 바렐 공격 높이는 발+10~75로 보아, 땅에서는 뒷주먹(높이100)에 닿지 않는다.
- 방패 판정은 일반 공격·기술·필살기·검기에 적용. 뇌격(마법)은 화면 전체 공격이라 몸에 바로 들어간다.
- 붙잡기 실패: 손등 치기10과 쥐어짜기18을 같은 틱에 준다(피격 무적 때문에 따로 주면 두 번째가 막힘). 다른 주먹은 잡기 마지막14틱 동안 날아온다.
- command 몸동작(32틱)과 주먹 패턴은 동시에 시작한다. 손등 치기는 반사 행동이라 몸동작 없이 나간다.
- 철벽·회오리 중에는 몸이 걷지도 돌지도 않는다(돌면 방패가 따라와 뒤로 돌아갈 수 없음).
- 20틱 규칙: 패턴별 첫·마지막 판정 시각 표(sovereign-data.js danger)와 실제 마지막 판정 시각으로 계산. 지면 파동이 화면에 남아 있는 동안은 새 패턴을 시작하지 않는다.
- 궁극기: 합체 뒤 플레이어에게서 먼 화면 끝에서 30틱 대기(바닥 전체 경고) → 무대 깊이 전체를 쓸고 → 20틱 뒤 반대로 → 끝에서 갈라짐.
  주먹은 그 자리에 누웠다가 몸이 일어나면 날아서 돌아온다. 높이 판정은 바렐 발 높이 50 미만. 첫 사용 뒤에는 모든 거리에서 가중치15(바르굴 방식).
- 피격 상/하단은 게임에 맞은 높이 정보가 없어 일반 타격=상단, 마무리 강타=하단으로 고른다.
- 체력 25% 넉다운·그로기 모두 kneel 그림을 쓰고, 이때도 두 주먹이 떨어져 눕는다.
- 유성 낙하: 같은 주먹이 다음 표식에 떨어지기 6틱 전에 앞 구덩이에서 사라진다.
- 1P 쓰러진 주먹: 1·6·7번의 자홍 핵을 회색으로 바꾼 그림을 미리 만들어 두고, 깨어날 때 원래 그림을 30틱 동안 겹쳐 밝힌다.
- 체력33% 이하에서 옆모습이 아닌 주먹은 붉은 외곽선으로 깜빡인다.
- 손등 치기 압박: 주먹이 하나라도 제자리에 있을 때 몸을 맞힌 횟수. 120틱 동안 안 맞으면 초기화.

5. 칸 수
- 몸 시트 16종: 모두 설계와 같음(1P hurt 5·5·4·4 = 18장).
- Merged_Giant_Fist 2줄: 칸 경계 방식으로 분리. 6번(갈라짐)은 반쪽만 남음.
- E1 5줄 fist_shatter: 파편이 떨어져 13조각으로 잡혀 가까운 것끼리 합쳐 10장.
- Beam 4줄 mark_alt: 11장.
- Beam 6줄 helm_beam: 한 줄로 이어져 있어 8등분(시작 1–3 / 반복 4–6 / 끝 7–8).
- Beam 7줄 eruption: 10장. Beam 8줄 reform: 9장.

6. 알려진 사항
- tests/regression.cjs·tests/boss-groggy.cjs의 boss5 검사는 블랙 문 엠페러 기준이다. SOVEREIGN_OVERRIDE=false로 돌려야 통과한다.
