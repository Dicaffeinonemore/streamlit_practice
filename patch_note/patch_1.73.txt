Lunatic Nights (흑월의 기사) v1.73 — 전투 HUD 개편 · 일시정지 및 설정 메뉴 개선
기록일: 2026-11-25

웹과 Godot의 전투 UI를 같은 디자인으로 정리했습니다. 바렐과 비에사의 전투 정보는
화면 왼쪽 위에 모으고, 보스는 체력바를 보는 것만으로 현재 페이즈를 알 수 있게 했습니다.
일시정지와 설정 메뉴에도 메인 메뉴와 어울리는 검은 철과 초승달 장식을 적용했습니다.

1. 플레이어 HUD
- 초상화 · 목숨 · 체력 · SP · 두루마리 · 점수 · 레벨 · 스킬을 202×88px 안에 모았습니다
  (960×540 기준). 점수와 레벨은 불투명한 점수판 안에 표시합니다.
- 바렐과 비에사는 같은 틀을 쓰며, 초상화와 이름, 스킬 그림은 선택한 캐릭터에 맞춰 바뀝니다.
- 초승달 아이콘 옆에는 남은 목숨을 표시합니다. HP는 진홍색, SP는 파란색으로 구분합니다.
- SP가 0이면 어두운 빈 트랙이 보입니다. 두루마리를 쓰면 해당 칸에는 어두운 실루엣만 남습니다.
- 스킬 슬롯 아래에 현재 단축키를 표시합니다. 재사용 대기 중에는 슬롯 안에 남은 시간이 표시됩니다.
- 테두리와 장식은 최종 표시 크기로 다시 그려 얇은 픽셀 선의 두께를 맞췄습니다.

2. 보스와 일반 적 체력 UI
- 보스 체력바를 화면 아래 가운데에 배치했습니다. 초상화, 이름, 페이즈 표시를 체력바와 함께
  보여 주며, 피해로 줄어든 양은 금빛 잔상으로 확인할 수 있습니다.
- 고라스 · 모르그라 · 아우렐리온 · 바르굴 · 소버린은 2페이즈에 진입하면 초상화와
  페이즈 표식이 바뀝니다. 그로기 진행도는 체력바 위의 작은 표식으로 표시합니다.
- 최근에 공격한 일반 적의 이름과 체력은 화면 오른쪽 위의 작은 이름판과 붉은 체력바로 표시합니다.

3. 일시정지 · 설정 메뉴
- 화면 오른쪽 위의 일시정지 버튼을 작게 줄였습니다. 일시정지 메뉴는 전투 화면 왼쪽 아래에
  놓고, 선택한 항목은 진홍색 강조 표시로 구분합니다.
- 설정 메뉴에 메인 메뉴 배경을 사용했습니다. 언어, 음악, 화면, 모바일 조작, 키 설정을
  메뉴에서 선택할 수 있습니다.
- 메인 메뉴의 기본 언어는 영어입니다. Options → Main menu language에서 한국어를 선택할 수
  있으며, 웹과 Godot이 같은 메뉴 번역을 사용합니다.

4. Godot 빌드
- Godot 13단계에서 Windows · Web 내보내기를 검증했고, Android · iOS 내보내기 프리셋도
  마련했습니다. 모바일 네이티브 빌드와 기기 검증은 후속 작업입니다.
- 이번 HUD를 포함한 Windows 확인용 빌드는 godot/build/windows-ui-v4/에 있습니다.
  LunaticNights.exe와 LunaticNights.pck를 같은 폴더에 두고 실행합니다.

파일

- godot/phase4/hud_design.gd · godot/phase3/presentation/stage_hud.gd: Godot 전투 HUD
- godot/phase4/title_art/menu.csv: 웹 · Godot 공용 메뉴 번역
- assets/aseprite/ui/hud-v4/ · tools/create-hud-v4.lua: HUD 원본, PNG, 팔레트, 9-slice 및 상태 정보
- godot/docs/PHASE13_REPORT.md: 플랫폼 내보내기 검증과 남은 항목

확인
- 웹 브라우저: 세 가지 화면 크기에서 스킬·일시정지 버튼 위치, 스킬 실행과 일시정지 조작,
  HP와 빈 SP 트랙, 다섯 보스의 페이즈별 초상화 확인.
- Godot: 바렐 · 비에사 시작, 일시정지 버튼과 페이즈별 초상화 로딩 검증 통과.
  새 Windows 빌드를 내보내고 시작 확인.
