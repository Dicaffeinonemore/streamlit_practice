Lunatic Nights (흑월의 기사) v1.74 — 이펙트 표시 순서 수정 · 캐릭터 선택 화면 개편
기록일: 2026-11-26

보스 스킬 이펙트가 캐릭터를 덮어 플레이어 위치를 알아보기 어렵던 문제를 고쳤습니다.
이제 모든 이펙트는 캐릭터 뒤에 표시됩니다. 캐릭터 선택 화면은 초상화 카드 디자인으로
바꾸고, 웹과 Godot에 같은 화면을 적용했습니다.

1. 이펙트 표시 순서 (버그 수정)
- 보스 스킬 이펙트가 캐릭터 위에 그려져 플레이어를 가리던 문제를 수정했습니다.
  예: 황금왕 아우렐리온의 불꽃 초승달.
- 화면에 그리는 순서는 다음과 같습니다.
  바닥 → 플레이어보다 뒤에 선 캐릭터 → 모든 이펙트 → 플레이어 → 플레이어보다 앞에 선 캐릭터
  → 투기장 울타리 등 앞쪽 배경
- 적용 대상: 다섯 보스의 투사체 · 충격파 · 낙하물, 바닥에서 솟는 불기둥(균열 분출),
  플레이어 기술 이펙트, 비에사의 화살.
- 데미지 숫자, 적의 "!" 공격 예고, 잡기 해제 게이지는 알림이라 계속 맨 위에 표시합니다.
- 필살기 중 화면이 어두워지는 연출과 뇌격 직전 화면이 푸르게 변하는 연출은 그대로입니다.
- 웹과 Godot에 같은 순서를 적용했습니다.

2. 캐릭터 선택 화면
- 캐릭터마다 초상화 카드를 표시합니다. 선택한 카드는 펼쳐지며 이름, 역할(근접 · 방어형 /
  원거리 · 기동형)과 힘 · 민첩 · 컨트롤 난이도 수치를 보여 줍니다.
- 바렐과 비에사 외에 공개되지 않은 III · IV 슬롯을 두었습니다. 화면 위쪽에 해금한
  캐릭터 수를 표시하며, 잠긴 카드를 고르면 "아직 해금되지 않은 캐릭터입니다." 안내가 잠시 나타납니다.
- 조작:
  · 방향키 / A · D / 게임패드 방향 입력: 카드 이동 (게임패드는 누르고 있으면 반복)
  · Enter / Space / 게임패드 A, 또는 선택한 카드를 다시 클릭: 여정 시작
  · Esc / Backspace / 게임패드 B: 뒤로
- 조작법 화면에서 캐릭터 선택으로 돌아오면 직전에 고른 캐릭터가 선택된 상태로 열립니다.
- 새 문구는 영어 · 한국어 메뉴 번역에 추가했습니다.
- 웹 단일 파일 빌드(build_standalone.py)와 Streamlit 서버(server.py)는 선택 화면의 그림과
  글꼴을 파일 안에 포함해 외부 파일 없이 동작합니다.

파일
- game.js: 이펙트 표시 순서(render), 캐릭터 선택 조작 · 게임패드
- godot/phase2/vertical_slice.gd · godot/phase3/stage_game.gd: Godot 캐릭터 · 이펙트 표시 순서
- godot/phase3/presentation/stage_top_view.gd: 울타리 전경과 이펙트를 별도 노드로 분리
- godot/phase2/presentation/actor_view.gd: "!" 공격 예고를 이펙트보다 위에 표시
- character-select.js · character-select.css · index.html: 웹 캐릭터 선택 화면
- godot/phase4/character_select/ · godot/phase4/menu_shell.gd: Godot 캐릭터 선택 화면
- assets/character-select/fonts/: 선택 화면 글꼴(Cinzel · 나눔명조 · Noto Sans KR, OFL 라이선스)
- godot/phase4/title_art/menu.csv: 메뉴 번역

확인

  앞에 있을 때를 각각 캡처했습니다. 두 경우 모두 플레이어가 이펙트 위에 보입니다.
- Godot: GUT 테스트 14개와 화면 렌더 검증 20항목이 모두 통과했습니다.

  Godot 메뉴 검증 32항목이 모두 통과했습니다.
