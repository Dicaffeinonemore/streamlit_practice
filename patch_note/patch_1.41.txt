비에사 전용 조작
J: 화살 / 공중 아래 30° 화살 + 체공. 사격 4번 이후 연계 가능. 공중 사격 종료 후 6틱 이내 재입력으로 체공 유지.
H: 지상 근접 콤보 slash1 → slash2 → kick. 기사와 같은 입력 버퍼/콤보 유예시간, 쿨타임 없음.
U: rapid_start → rapid_loop 3회 → rapid_end. 1·4번 프레임마다 총 6발. 위/아래로 다음 발 레인 조절. 쿨타임 4.6초.
L: 조준 유지·해제 관통 저격. 일찍 놓아도 최소 30틱 조준 후 발사. 120틱 유지 시 자동 발사. 쿨타임 6.5초.
O: 1~4번 전진, 5~6번 베기 → 낮은 백플립 → 착지. J 입력 무시. 쿨타임 7초.
P: 지상/공중 돌진 → 높은 백플립 → 최대 40틱 약한 중력 체공. J로 공중 사격 연계. 착지 전 공중 P 한 번. 쿨타임 8초.
K: SP100 소모 필살기 ‘흑월 난사’. 시전 전체 무적.
공통: WASD/방향키 이동, Space/Ctrl 점프, Shift/방향키 두 번 대시, ESC 일시정지/메뉴, M 음소거.
기본 설정에서 키 충돌 없음. 저장된 키 재설정은 기존 입력 매핑을 따름. Z/X/I/V의 기사 공격·필살·뇌격 보조 조작은 비에사에서 발동하지 않음.
바렐 선택 시 기존 조작 유지. 선택창·조작 안내·설정·모바일 버튼 이름을 비에사에 맞춰 표시.

필살기 ‘흑월 난사’
- 도약4번부터 상승하여 키 × 1.2 높이 도달 → 소환 → 50틱 난사 → 마무리.
- 틱당 환영 화살4발, 총200발. 모양4종 무작위, 60%는 전방의 살아있는 적 근처로 조준.
- 화살당 0.08J, 같은 적은 3틱 간격으로만 피격. 3발마다 착탄 이펙트, 4틱마다 연출용 volley.
- 투사체·이펙트 객체 풀 재사용. 착탄 이펙트는 최대128개로 제한.
- 마법진 등장·3~5번 반복·6번 소멸. 마무리3번에서 거대 화살 발사.
- 폭발 반경 키 × 1.2, 피해 3.0J, 다운 및 화면 흔들림. 이후 낙하·착지·기립.
- 배경만 30% 어둡게 처리하며 다른 캐릭터·적은 원래 밝기로 표시.
- HP80, 이동1.1배, 대시거리1.15배, hurtbox0.9배 및 기사 공통 피격/다운/기상 무적·사망·저장 흐름 유지.
- 새 게임과 보스 챌린지에서 선택 가능. 저장/이어하기는 characterId를 유지.
