흑월의 기사 v1.37 — 바르굴 패턴 개선·모든 보스 그로기 자세 변경
기록일: 2026-10-21

v1.36의 바르굴 구현과 후속 수정 사항을 아래 최종 상태로 정리한다.
기존 patch_note/patch_1.36.txt 및 단계별 보고서·실행 결과는 당시 기록으로 보존한다.

1. 바르굴 전투 연결 및 확정 조정
- 4스테이지 보스 바르굴: 왕좌 등장 → 1페이즈 HP2000 → 변신 → 2페이즈 HP2500.
- 빙창3연격·쾌속돌진·빙검소환·십자빙결·얼음구슬·창휘두르기·냉소·궁극기를 사용한다.
- 바르굴의 체력 문턱 증원은 끄고, 처음 웨이브의 궁병1명은 유지한다. 다른 보스의 증원은 유지한다.
- P2 3연격의 실제12장은 시동, 13–14장만 3타 공격7틱으로 확정. 총79틱·후딜22틱 유지.
- 창 사거리와 공격 상자는 그림 실측값을 사용한다.
- P2 귀환 돌진: 흰 예고18틱, 예고8틱째 줄을 한 번 고정하고 출발까지10틱 동안 추가 추적하지 않는다.
  마지막 후딜34틱·전체174틱. 첫 돌진은 유지한다.
- 빙검: 마지막 빙검 판정이 끝날 때까지 마지막 집중 그림 유지 → 후딜24틱.
  집중 유지 중 아머 없음. 맞으면 일반 피격으로 끊기지만 이미 놓인 표식은 남는다.
  P1 전체143틱 / P2 전체151틱.
- 십자: 가로 팔은 현재 카메라의 화면 폭 전체(VW640 월드px)를 덮는다.
  세로 팔은 무대 깊이 전체·x±18.4032 유지. 경고 그림은 가로 팔 방향으로만 늘린다.
- 구슬 소환 후딜은 두 페이즈 모두36틱.

2. 얼음 구슬 — 독립 AI 소환 적
- 플레이어를 중심으로 도는 고정 궤도 대신, 독립적으로 접근·후퇴·거리 유지하며 부유하는 적2개 소환.
- 각 HP30과 체력바를 가진다. 일반 공격·검기·기술·필살기·뇌격의 실제 피해로 HP가 줄고, HP0이면 깨진다.
- 기존 두 번 피격 파괴와600틱 자동 소멸을 제거한다. 일반 피해10 기준으로는3회 적중에 파괴된다.
- 구슬이 하나라도 살아 있으면 추가 소환 불가. 모두 파괴된 뒤720틱 재소환 쿨타임 시작.
- 각 구슬이 빙결 마탄을 발사한다. P1 각200틱마다1발 / P2 각150틱마다2발.
  첫 사격 시점을 분산하고, 발사 전20/17틱 반짝임을 표시한다. 마탄 피해는 P1 8 / P2 10.
- 플레이어가 쓰러져 있는 동안 사격하지 않는다. 구슬 파괴마다 바르굴 그로기+20·짧은 히트스톱.
- 보스 변신·사망 때 구슬과 관련 공격을 정리한다.
- 구슬 표시 크기를30×30에서42×42 월드px로40% 확대하고 체력바 위치·폭을 맞췄다.
  공격받는 몸 판정은 기존 크기를 유지한다.
- 상세: docs/boss4_vargul_orb_ai_report.md

3. 패턴 크기 안정화·3연격 범위 이펙트
- 웅크리거나 기울어진 일부 프레임이 과대 확대되던 현상을 렌더 배율 보정으로 억제한다.
- 페이즈별 대기 자세의 몸 면적을 기준으로 큰 프레임만 축소한다. 작은 자세는 추가 확대하지 않는다.
- 발 피벗을 유지하고 문신 마스크에도 같은 배율을 적용한다. 왕좌·사망 잔해는 보정 대상에서 제외한다.
- 3연격에 공격 직전의 옅은 냉기 표시와 공격 중 창 궤적·창끝 섬광·얼음 가루·바닥 범위를 추가한다.
- 이펙트는 실제 공격 상자의 방향·거리·높이·깊이·판정 틱에 맞춘다. 두 페이즈와 좌우 방향 모두 적용.
- 이 보정에서 원본 시트·아틀라스는 재처리하지 않았으며 피해·공격 사거리·타이밍은 유지한다.
- 상세: docs/boss4_vargul_visual_fix_report.md

4. 궁극기 — 창 내려찍기와 연속 빙결파
- 거대 창만 떨어뜨리는 방식에서 바르굴이 직접 공중으로 오른 뒤 빠르게 강하하는 빙결 강타로 변경.
- 고정 표식 지점으로6틱 동안 강하하며 p2_cast7→8장의 창 내려찍기 모션을 사용한다.
- 착지 후 창을 바닥에 꽂은 집중 자세를 유지한다. 착지 지점 뒤로 순간 이동하지 않는다.
- 착지 중심은8틱 동안30피해. 착지8틱 뒤부터24틱 간격으로3겹의 빙결파를 연속 방출한다.
- 각 빙결파는36틱 동안 바깥으로 확장하며13피해. 움직이는 파면에만 판정이 있고 지나간 내부는 안전하다.
- 빙결파는 점프로 넘을 수 있다. 세 파동은 기술149/173/197틱에 시작하고 마지막은232틱까지 진행된다.
- 공중 소실·강하·충돌 구간의 무적을 유지하며, 기술160–249틱의 창을 꽂은 후딜90틱에는 반격할 수 있다.
- 2페이즈 HP35% 이하 첫 우선 사용·쿨타임900틱·전체268틱 유지.
- 공략: 고정 표식 중심 이탈 → 연속으로 밀려오는 파면을 보고 점프 → 창을 꽂은 동안 반격.
- 최신 상세: docs/boss4_vargul_ultimate_spear_report.md
  docs/boss4_vargul_ultimate_slam_report.md의 단일 파동은 중간 구현 기록이며 위3파동 규칙으로 대체됐다.

5. 모든 보스 — 서서 비틀거리는 그로기
- 1–5스테이지 모든 보스와 두 페이즈의 그로기 자세를 서서 비틀거리는 모습으로 통일한다.
- 전용 렌더러와 레거시 렌더러에 모두 적용하며, 발을 기준으로 몸이 흔들린다.
- 그로기300틱(5초)·받는 피해1.5배·피격 가능 상태·머리 위 기절 표시는 유지한다.
- 체력 문턱에서 실제로 쓰러지는 넉다운, 페이즈 전환과 사망 동작은 유지한다.
- 상세: docs/boss_groggy_standing.md
