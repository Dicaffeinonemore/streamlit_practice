흑월의 기사 v1.25 — Barel 주인공 이미지 적용 시험

지정된 Barel 이미지 모음의 원화·동작·이펙트를 게임에 적용.
- 녹색 배경을 제거한 주인공: 대기, 9프레임 보행, 3연타, 공중 공격,
  대시, 점프, 피격, 넘어짐/기상, 사망, 전투 기술, 필살기, 마법.
- 원화 기반 HUD 초상화와 새 캐릭터의 대시 잔상.
- 푸른 검기, 상승 참격, 지면 충격, 초승달, 번개, 이동 먼지 사용.
- 스킬 5종을 효과 이미지 아이콘으로 변경. 단축키, 쿨다운 숫자,
  준비 상태 테두리, 툴팁과 접근성 이름 유지.
- 기존 피해량·판정·쿨다운 및 저장 데이터 형식 유지.
- 188개 프레임을 로컬 아틀라스로 생성. Streamlit 단일 HTML에도 포함.

원본 파일은 변경하지 않음. 비균일 배치 때문에 캐릭터는 실루엣 단위로
분리하고 효과는 확인한 행/열 경계로 재단. 투명 가장자리의 녹색 번짐 제거.
격자선이 있는 필살기 수정본 대신 격자선 없는 초기본 사용.
연결되지 않은 작은 장식 조각은 제외됨.

재생성: Python(Pillow, NumPy)으로 tools/build_barel.py <Barel_All_Images 경로>
검증: node tests/regression.cjs (전투, UI, 모바일, 단일 HTML, Barel 렌더링)
실행: python server.py 또는 python -m streamlit run server.py
