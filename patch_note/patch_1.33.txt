흑월의 기사 v1.33 — 황금왕 아우렐리온 교체

1. 바뀐 파일과 이유
- aurelion-art.js: 동작 15종 115프레임, 더하기 FX 8종 33프레임과 원본 전투 데이터.
  4096×1069 / 4096×376 WebP q88 두 장. JS 전체 1,602,583바이트(약 1.60MB).
  알파 경계의 디코딩 전후 바이트 비교 통과. PNG 예외 없음.
- aurelion-runtime.js: 패턴 선택, 반복 타임라인, 수호, 공격/투사체 판정,
  이미지 즉시 로딩, 예고, 초상화, 잔상, 검 끝, 등장/전환/사망 렌더링.
- assets/aurelion/: 원본 PNG/JSON/DESIGN 보존, 출처별 SHA-256,
  묶음 시트, frames.json, build-report.json. 원본은 수정하지 않음.
- tools/build_aurelion_art.py: 검증 후 결정적으로 빌드. ZIP 속 도구는 실행하지 않음.
- tools/boss_art_common.py 및 build_gorath.py/build_morgra.py:
  기존 타일 패킹을 공통 함수로 추출. 기존 아틀라스 출력 좌표/픽셀은 유지.
- game.js: 기존 보스 연결 지점에 boss3 분기와 반응형 수호 호출만 추가.
  기존 boss3 정의/패턴/HD/named 아트는 보존.
- server.py / index.html: 아우렐리온 art → runtime → game.js 순서로 포함.
  빈 data favicon을 사용해 브라우저의 자동 favicon HTTP 요청도 방지.
- tests/aurelion.cjs, tests/aurelion-build.py, tests/regression.cjs:
  새 보스 검증 및 기존 브라우저 테스트 하네스 재사용.
- README.md: 상단에 현재 실행 방법과 보스 목록 추가.
- artifacts/aurelion-1.33/: 기술별 화면 및 기계 판독 가능한 results.json.

2. 기존 보스 방식과 다른 부분
- 프레임 형식 {atlas, anchor}에 sheet 번호만 추가. 아트/런타임 분리 및 즉시 로딩은 동일.
- 단일 히트 플래그 대신 펼친 타임라인의 그림 인스턴스별 타격 기록을 사용.
  프레임을 건너뛰어도 지나간 이벤트를 모두 실행하며 동일 시간 재평가/되감기로 중복 생성하지 않음.
- 수호는 damageEnemy 진입부에서 차단. 일반 공격에는 HP/점수/그로기/콤보 변화가 없고
  플레이어 체력·무적을 건드리지 않는 기존 hurt 경직을 적용.
- 무거운 기술과 뇌격은 정상 피해 + 자세 붕괴 그로기 30.
  이후 공통 피해 그로기 증가/기절/체력 비율 다운/페이즈 전환이 우선함.
- 공통 기절 자세에 쓰는 knockdown 그림의 무적 구간은 기절에 복사하지 않음.
  기절 중 1.5배 피해와 공통 콤보 보너스를 그대로 유지.
- boss3만 등장 142틱, 전환 100+142=242틱, 사망 121틱 재생+50틱 유지.
- USE_AURELION_V133=false이면 이미지·기술명·패턴·판정·투사체·초상화·연출을 모두 1.32로 복귀.
  테스트는 런타임 로드 전에 AURELION_V133_OVERRIDE=false를 주입하여 같은 플래그를 검사.

3. 단위 및 공통 수치
- HP 1500, HP 750에서 2페이즈, 체력바 하나. JSON의 HP/그로기/기절/배율/heavy 항목은 사용하지 않음.
- K=.55×.85=.4675, 대기 왕관~발 높이 약112.2 월드 px. 모르그라와 같은 변환.
- 공격/피격 박스, 이동, 투사체 속도, 이벤트 offset, 거리대 및 수호 반응 거리에 K 적용.
  near=70.125, mid=158.95, 돌진 반복 거리=60.775, 충격파 step=33.66.
- depth는 배율 없는 월드 값. 표식 깊이 ±48은 ±36으로 조정.
- 근접 줄 정렬12 / 원거리20. 동시 공격 제한 및 플레이어 다운 중 새 공격 금지 유지.
- 플레이어 무적40틱, 기존 hurtPlayer, 피해 배율, 부하 rogue 2명 소환 경로 유지.
- 2페이즈 시동 .85는 원본 S 구간을 건너뛰는 타임라인으로 적용.
- 검기3/4발, 충격파4/7개, 3연참 최대3회, 선풍12회. 각 바퀴 마지막 선풍 타격은 다운 속성.
- 표식은 생성 순간 위치 고정, 그림 간격13틱, 150ms 점멸. 시전 중단 시 제거.

4. 예상 처치 타수/시간
아우렐리온: 89회 명중 / 2,668틱 / 약44.47초.
모르그라(850+1200): 117회 명중 / 3,456틱 / 57.60초.
아우렐리온은 이 조건에서 명중 타수 약24%, 소요 시간 약23% 적음.
조건: 첫 일반 공격만 반복, 파워업 없음, 보스 공격/회피/접근 시간 제외,
같은 위치에서 실제 플레이어 공격 애니메이션과 공통 콤보·그로기·다운·전환/부활·히트스톱 적용.
실전 클리어 시간 예측치가 아니라 같은 화력의 비교용 통제 실험이다.
실전에서는 수호, 이동, 패턴 대기, 기술/필살기 사용에 따라 크게 달라진다.

5. 반격 검사
현재 1타 판정: ceil((90+110×.35)/(1000/60))=8틱. 사거리80 + 현재 그림의 e.hw.
걷기3.1, 깊이 이동2.325, 대시80px/150ms, 110ms 이후 공격 연결을 실제 updPlayer로 실행.
JSON punish_check의 x거리에 K 적용, lane_gap은 월드 값 유지.
두 페이즈 결과가 동일하다. '대시' 열은 가로 거리가 멀 때 먼저 대시한 뒤 줄을 맞추는 경로다.

기술                  x거리 / 줄차이      틈     걷기→명중  대시 경로→명중
왕검 3연참             56.10 / 0          26       8            8
황금 검기             121.55 / 32         22      14           24
황금중파참             60.78 / 40         66      15           15
왕의 돌진              56.10 / 34         38      13           13
황금의 엄벌            74.80 / 0          54       8            8
수호 방치              51.43 / 0          24       8            8
수호 붕괴              37.40 / 0          70       8            8
황금 선풍              93.50 / 0          60       8            8
도발                   93.50 / 0          86       8            8

각 기술에 가능한 접근 경로가 있으므로 반격 틈 수치는 변경하지 않음.
검기는 대시 후 줄 정렬 경로만 2틱 초과한다. 그 경로까지 허용하려면 1.34에서
검기 반격 틈 22→24틱을 검토할 수 있으나, 현재는 사선 걷기로 14틱에 명중하므로 필수 변경은 아니다.
검사는 회수 시작 위치에서의 입력 가능성을 평가하며, 이전에 생성된 투사체를 모두 회피하는 자동 공략은 아니다.

6. 3연참·선풍의 실제 명중
플레이어를 타격 범위에 계속 두고 실제 updPlayer의 피격 무적·다운 회복을 유지한 검사.
3연참은 full 시퀀스. 타임라인 시작을 0으로 한 프레임:
- 1페이즈 3연참: 16 / 56, 2회, 9+14=23 피해.
- 2페이즈 3연참: 14 / 54, 2회, 공통1.3배 반올림으로12+18=30 피해.
- 1페이즈 선풍: 22 / 62, 2회, 7+7=14 피해.
- 2페이즈 선풍: 19 / 59, 2회, 공통1.3배 반올림으로9+9=18 피해.
첫 타 이후 40틱 무적으로 중간 타격이 무효가 되며, 3연참은 마지막 타의 유효 구간에서 다시 맞는다.
실제 이동/점프/첫 타 회피에 따라 명중 횟수는 달라진다. 플레이어 무적은 변경하지 않았다.

9. 남은 문제와 1.34 제안
- 자동 검증은 사람의 실전 난이도 평가를 대신하지 않는다. HP/공격력은 이번에 추가 조정하지 않음.
- 반격 가능 여부는 정해진 출발 거리와 줄 차이 기준. 화면 끝/잔여 검기/수호 읽기까지 포함한
  실전 처치 시간과 피격률을 수집한 뒤 1.34에서 HP·수호 빈도·반격 틈을 검토할 것.
- 검 끝은 새 그림의 공격 박스 끝/이벤트 blade_tip offset에서 계산한다.
  판정이 없는 그림에는 해당 동작의 이벤트 위치 또는 기본 자세 기준 위치를 쓴다.
- 프레임 성능은 Windows headless Chrome의 1280×720, 기본 효과, 각 보스 단독 1페이즈
  60초 표본이다. 플레이어는 측정을 지속하기 위해 무적이며 공격하지 않는다.
  실제 기기/브라우저/해상도에 따라 달라지므로 절대 성능 보장은 아니다.
