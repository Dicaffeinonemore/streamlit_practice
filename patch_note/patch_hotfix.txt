1. 사운드 오류 수정
- Streamlit 배포 환경에서 소리 활성화가 막힌 경우, 이후 클릭·터치·키 입력으로 다시 활성화를 시도하도록 수정했습니다.
- 보스전 배경음악 boss.mp3를 배포용 HTML에 직접 포함하도록 변경했습니다. 별도의 MP3 주소를 불러오지 않고 재생합니다.
- 사용자가 설정한 음소거와 일시정지 상태는 유지됩니다.

2. 스킬 방향 오류 수정
- L키 장거리 검기가 입력 방향과 달리 뒤쪽 적을 향해 발사되는 문제를 수정했습니다.
- 다른 방향성 스킬과 필살기에도 같은 방향 처리 기준을 적용했습니다.
- 좌우 이동 입력이 있으면 해당 방향을 우선하며, 입력이 없으면 현재 바라보는 방향을 유지합니다.
- 뒤쪽 적을 자동으로 선택하거나 추적하면서 공격 방향이 뒤집히는 문제를 수정했습니다.
- I키 뇌격의 광역 공격 범위는 유지됩니다.

3. 전투 UI 개선
- 플레이어 체력바, 스크롤, 스킬, 남은 목숨, 일시정지 버튼에 새 UI 이미지를 적용했습니다.
- 플레이어 체력바와 스킬 UI의 원본 비율을 유지하고, 스킬 UI를 스크롤 아래에 배치했습니다.
- 일시정지 버튼을 축소해 오른쪽 맨 위로 옮겼습니다.
- 스테이지 UI와 플레이어 체력바 아래의 텍스트를 제거했습니다.
- 점수를 왼쪽 맨 위에 'score 숫자' 형식으로 표시합니다.
- 보스 체력바에 새 이미지를 적용하고 화면 아래쪽으로 배치했습니다. 등장 인트로가 끝난 뒤 체력바가 나타납니다.
- 일반 적 체력 UI를 오른쪽 위 일시정지 버튼 아래로 옮기고 새 프레임을 적용했습니다.
- 일반 적 체력 UI의 원 안에는 해당 적의 초상화, 체력바 위에는 적 이름을 표시합니다. 붉은 체력바는 실제 남은 체력에 맞춰 줄어듭니다.

4. 보스 챌린지 추가
- 지금까지 물리친 보스와 다시 대결할 수 있는 보스 챌린지 메뉴를 추가했습니다.

적용 안내
- 위 내용은 수정된 게임 파일 기준입니다. Streamlit 공개 페이지에는 변경 파일을 저장소에 반영하고 재배포한 뒤 적용됩니다.
