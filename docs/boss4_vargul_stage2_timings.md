# v1.36 바르굴 — 2단계 전체 그림별 실행 시간표

실행 원본: [results.json](../artifacts/vargul-1.36/runtime/results.json). Chrome CDP의 실제 F6 선택·F7 반복 입력으로 각 기술을 두 번 시작했다. 첫 회를 아래에 기록했다. 쿨타임·연속 제한은 반복 모드에서만 생략하며, 이전 표식·구슬 수명은 유지한다.

**τ=0은 기술의 첫 실행 틱이다.** 예를 들어 τ0–17은18틱, τ18이 첫 판정이다. S=시동/연결/집중, A=공격, R=명시된 빈틈이다. S라도 아머가 없는 동작은 공통 피격 경직으로 끊긴다. 판정 상자가 있는 A만 보스 몸에서 공격 판정을 낸다. 장판 A는 별도 hazard에서 판정한다.

시뮬레이션 틱만 센다. 실제 플레이의 히트스톱·일시정지는 이 시간을 멈춘다. 최대 거리 돌진의 기록이며 화면 끝에 먼저 닿으면 이동 A만 짧아지고 급정지·최종 R 길이는 유지한다.
